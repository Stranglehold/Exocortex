## Autonomous Factor Investing: AlphaAgent

**Key Paper:** AlphaAgent: LLM-Driven Alpha Mining with Regularized Exploration (KDD 2025, arXiv 2502.16789)

**What it does:**
- Autonomous multi-agent framework that discovers decay-resistant alpha factors
- Integrates LLM agents with regularization mechanisms
- Balances originality, financial rationale, and complexity control

**Key Paper:** Autonomous Factor Investing via Agentic AI (arXiv 2603.14288, Mar 2026)

**What it does:**
- Self-directed agentic AI engine that autonomously generates interpretable trading signals without sequential manual prompts
- Mitigates data snooping via closed-loop system enforcing strict out-of-sample validation and economic rationale requirements
- **Performance**: long-short portfolios from linear combination of AI-generated signals achieve annualized Sharpe ratio of 3.11 and return of 59.53% on U.S. equity market
- **Key insight**: self-evolving AI approach provides scalable, interpretable paradigm for systematic factor investing
- **Validation**: strict out-of-sample checks prevent backtest overfitting — pervasive challenge in automated ML quant finance

## Recent Developments (2026)

### FactorMiner: Self-Evolving Agent with Skills and Experience Memory
**Paper:** FactorMiner: A Self-Evolving Agent with Skills and Experience Memory for Financial Alpha Discovery (arXiv 2602.14670, Feb 2026)

**Key Innovation:**
- Self-evolving agent architecture with persistent skill library and experience memory
- Parallel evaluation of multiple factor hypotheses
- Intraday prediction capabilities
- Experience memory allows the agent to learn from past factor successes/failures

**Significance:** Represents the next evolution beyond AlphaAgent — moving from single-session factor mining to persistent, self-improving agents that accumulate expertise over time.

### Hubble: Safe and Automated Alpha Discovery
**Paper:** Hubble: An LLM-Driven Agentic Framework for Safe and Automated Alpha Discovery (arXiv 2604.09601, Apr 2026)

**Key Innovation:**
- Closed-loop factor mining framework with safety constraints
- Addresses overfitting in genetic programming approaches
- Produces interpretable formulas (unlike black-box genetic programming)
- Automated workflow from hypothesis to backtesting

**Significance:** Addresses the interpretability and safety concerns that have limited production deployment of automated factor discovery.

### Cognitive Alpha Mining via LLM-Driven Code-Based Evolution
**Paper:** Cognitive Alpha Mining via LLM-Driven Code-Based Evolution (arXiv 2511.18850, Nov 2025)

**Key Innovation:**
- Combines LLM reasoning with evolutionary algorithms
- Code-based representation of factors enables more sophisticated operations
- Addresses limitations of pure genetic programming and pure LLM approaches

**Significance:** Demonstrates hybrid approaches that combine the strengths of different methodologies.
