# 🚀 Agent Zero v1.7 — Complete Feature Summary

**Release Date:** April 3, 2026

---

## ✨ New Features

### 1. Early Tool Dispatch via Streaming JSON Detection

| Aspect | Details |
|--------|--------|
| **What it does** | Tool calls execute as soon as the first complete JSON object is detected in the model stream |
| **How it works** | The `DirtyJson` parser exposes a `completed` flag when the root brace-delimited object closes; extraction stops there instead of waiting for trailing tokens |
| **Performance Impact** | ⚡ **Faster response times** — no longer waits for full token generation before executing tools |

### 2. Plugin Discovery Cards on Welcome & Onboarding

| Aspect | Details |
|--------|--------|
| **What it does** | Feature cards appear on welcome/dashboard surface highlighting the Plugin Hub and integrations (Telegram, Email, WhatsApp) |
| **Implementation** | Always-on `_discovery` plugin using existing WebUI extension mechanism — no core code rewrites |
| **User Experience** | Persistent dismiss/restore functionality with CTAs leading to relevant plugin config screens |
