### Part 2: WinTAK Server Architecture

**WinTAK (Windows TAK)** is the Windows counterpart to ATAK (Android TAK), both part of L3Harris's TAK (Tactical Assault Kit) ecosystem. Military C2 platform for real-time shared situational awareness.

**Architecture Components:**
- **COAST (Common Operating Picture Server)**: Central server maintaining shared tactical picture
- **PTT (Persistent Transport)**: Message bus using MQTT/HTTP for data distribution
- **GIS Engine**: Map-based primary view with layered data (entities, relationships, annotations)
- **Event Protocol**: UAST (Universal Adaptive Schema Technology) for standardized event messaging
- **Data Layers**: Persons, Organizations, Locations, Events, Documents, Relationships (confirmed/inferred/contested), Annotations, Provenance, Temporal

**Data Flow:**
```
[WinTAK Clients] ↔ [COAST Server] ↔ [PTT Message Bus] ↔ [Data Sources]
                              ↓
                    [Event Protocol (UAST)]
                              ↓
                    [Shared Tactical Picture]
```

**Integration Points:**
- COAST exposes REST APIs for event ingestion/query
- Supports XML/JSON event payloads
- Can interface with external GIS systems
- Temporal data model supports historical replay
