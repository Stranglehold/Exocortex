## OSS (Open Source Signals) — Intelligence Ledger

**Purpose:** Intelligence ledger for open-source signal collection and analysis. Ingests RSS feeds, extracts claims via LLM, deduplicates via FAISS embeddings, and tracks narrative patterns.

**Data:** SQLite at `/a0/usr/oss/oss.db`, FAISS index at `/a0/usr/oss/claims.index`

### Available Tools (13 tools)

| Tool | Purpose |
|------|---------|
| `oss_topic` | Query claims about a topic from the ledger |
| `oss_drift` | Detect narrative framing drift for a topic |
| `oss_dynamics` | Propagation velocity, alert level, time-to-escape analysis |
| `oss_hypotheses` | List/register/confirm/falsify/promote competing hypotheses |
| `oss_health` | System operational health report |
| `oss_submit` | Log a new claim directly to the ledger (analyst dictation) |
| `oss_list_topics` | List all monitored topics with claim counts |
| `oss_add_topic` | Register a new topic tag for the ingestion pipeline |
| `oss_ingest_pause` | Pause the automated RSS ingestion pipeline |
| `oss_ingest_resume` | Resume the automated RSS ingestion pipeline |
| `oss_question` | Manage analyst active questions (create/evolve/list/deactivate) |
| `oss_synthesize` | Ask the ledger a question; receive evidence-based synthesis |
| `oss_ingest_sprint` | Run a bounded ingestion sprint — fetch RSS, extract claims, deduplicate, summarize |

**Key Capability:** The analyst works inside the pipeline — directs attention via active questions, challenges classifications, reviews rejections, and receives evidence-based answers via synthesis. Integrates with SWARMFISH for prediction.

## SWARMFISH — Analytic Consensus Engine

**Purpose:** Analytic consensus engine with eight analytical profiles that independently assess prediction questions then aggregate to a consensus.

**Profiles:** Base Rate Analyst, Contrarian, Historian, Reflexivity Modeler, Decomposer, Network Analyst, Sentiment Decoder, Risk Manager

**Data:** SQLite at `/a0/usr/swarmfish/swarmfish.db`

### Available Tools (5 tools)

| Tool | Purpose |
|------|---------|
| `swarmfish_predict` | Submit a prediction question to the committee |
| `swarmfish_session` | Get prediction session detail with configurable deliberation transparency (levels 1-3) |
| `swarmfish_sessions` | List all prediction sessions |
| `swarmfish_calibration` | Domain-specific calibration of prediction accuracy |
| `swarmfish_outcome` | Record actual outcomes for calibration tracking |

**Key Capability:** Configurable committee composition, full deliberation transparency, dissent as a first-class object, persistent sessions, and domain-specific calibration.

---

## Integration Pattern

These plugins work together in an intelligence workflow:
1. **OSS** collects and structures signals from open sources
2. **Analyst** directs attention via active questions and hypotheses
3. **SWARMFISH** provides structured prediction on key uncertainties
4. **Outcomes** feed back into calibration for improved future predictions

Both systems maintain persistent state in SQLite databases and auto-create their data stores on first use.
