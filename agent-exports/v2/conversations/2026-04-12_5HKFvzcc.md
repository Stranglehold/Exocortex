# Python Sort Function

## Basic Implementation

```python
def sort_list(lst, reverse=False):
    """
    Sort a list of comparable elements.
    
    Args:
        lst: The list to sort
        reverse: If True, sort in descending order
    
    Returns:
        A new sorted list (original unchanged)
    """
    return sorted(lst, reverse=reverse)
```

## Usage Examples

```python
# Sort numbers
numbers = [64, 25, 12, 22, 11]
sorted_numbers = sort_list(numbers)
print(sorted_numbers)  # [11, 12, 22, 25, 64]

# Sort strings
words = ['banana', 'apple', 'cherry']
sorted_words = sort_list(words)
print(sorted_words)  # ['apple', 'banana', 'cherry']

# Reverse order
sorted_desc = sort_list(numbers, reverse=True)
print(sorted_desc)  # [64, 25, 22, 12, 11]
```

## Alternative: In-Place Sorting

```python
def sort_list_inplace(lst, reverse=False):
    """Sort list in-place (modifies original)."""
    lst.sort(reverse=reverse)
    return lst
```

**Note:** Python uses **Timsort** — O(n log n) time complexity, stable sort, highly optimized for real-world data.
