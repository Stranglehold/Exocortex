# **OSS (Office of Strategic Services)** - Architecture & Tools

## Overview

**OSS V2.0.0** is a **Cognitive Defense System** designed for tracking claims, detecting narrative manipulation techniques, measuring propagation dynamics, and maintaining competing hypotheses.

---

## System Architecture

| Component | Details |
|-----------|---------|
| **Database** | `/a0/usr/oss/oss.db` (SQLite) |
| **Service Port** | `7731` |
| **Version** | `2.0.0` |
| **Type** | Cognitive Defense / Intelligence Ledger System |

---

## Core Capabilities

### 1. **Claim Tracking & Analysis**
- Claims enter as **STAGED** status
- Requires `/admin/promote_claim` for permanent record
- Tracks narrative manipulation techniques
- Measures propagation dynamics

### 2. **Alert Level System**
| Level | Description |
|-------|-------------|
| **INFORMATIONAL** | Baseline monitoring |
| **WARNING** | Spreading faster than expected or broad cluster coverage |
| **URGENT** | Time to escape velocity < 24h (operator response baseline) |

### 3. **Hypothesis Management**
- Maintains competing hypotheses
- Drift analysis over time
- Dynamics tracking

| Tool | Purpose |

### Query & Interaction
| Tool | Purpose |
|------|---------|
| `oss_question` | Create questions for analysis (requires `action=create`, `topic`, and `text` parameters) |

---

## Key Design Principles

1. **Staged Claims Pipeline** - All claims start as STAGED, requiring explicit promotion
2. **Multi-Hypothesis Tracking** - Maintains competing explanations simultaneously
3. **Drift Detection** - Monitors how narratives evolve over time
4. **Dynamic Alerting** - Three-tier alert system based on propagation velocity
5. **Operator-in-the-Loop** - Human oversight required for critical decisions

---

## Example Usage Pattern

```python
# Create a question for analysis

# Track dynamics over time
oss_dynamics(topic="geopolitical")

# Analyze narrative drift
oss_drift(topic="geopolitical")

# View interactive panel
oss_panel(view="sessions")
```
