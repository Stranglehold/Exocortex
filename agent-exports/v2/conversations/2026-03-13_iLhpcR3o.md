1. When the Python process starts, `model_tools.py` is imported

**Why hot-reload doesn't work:**

- The `_discover_tools()` function only runs once, during initial module import

1. Fresh Python process starts
2. `model_tools.py` imports with the updated `_modules` list (including `"tools.oss_tools"`)
3. `_discover_tools()` runs and imports `oss_tools`
