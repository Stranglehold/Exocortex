# 🧠 AgentEvolver Self-Improvement Plugin - Deep Dive

## Overview

The **agentevolver_self_improvement** plugin implements three self-evolving mechanisms from the [AgentEvolver research paper](https://arxiv.org/abs/2503.18694) by Yunpeng Zhai et al., 2025, enabling autonomous agents to improve through experience.

---

## 🎯 The Three Self-Evolving Mechanisms

### 1️⃣ **Self-Questioning** (Task Generation)

The agent generates its own training tasks based on past experiences and current capabilities.

**How it works:**
```python
# Generates tasks in categories: "coding", "research", or "general"
# Difficulty levels: "easy", "medium", "hard"
task = engine.generate_task(category="coding", difficulty="medium")
```

**Example generated task:**
> "Create a Python function that parses log files and extracts error patterns, then generates a summary report."

---

### 2️⃣ **Self-Navigating** (Experience Retrieval)

The agent retrieves relevant past experiences to guide current decision-making.

**How it works:**
```python
# Retrieves up to N most recent experiences for a task type
experiences = engine.get_relevant_experiences(task_type="coding", max_results=5)
```

**What gets stored per experience:**
- Task description and type
- Actions taken (list of steps)
- Outcome (`success`, `partial_success`, or `failure`)
- Lessons learned (key insights)
- Timestamp and metadata

---

### 3️⃣ **Self-Attributing** (Credit Assignment)

The agent analyzes which actions contributed to success or failure, assigning scores with temporal discounting.

**How it works:**
```python
# Analyzes action-outcome pairs
actions = ["read_file", "parse_data", "generate_report"]
outcomes = ["success", "partial_success", "failure"]
scores = engine.analyze_actions(actions, outcomes)
```

**Scoring formula:**
- Success: 1.0 × (0.9^position) 
- Partial success: 0.5 × (0.9^position)
- Failure: 0.0 × (0.9^position)

Earlier actions get slightly less credit due to temporal discounting.
