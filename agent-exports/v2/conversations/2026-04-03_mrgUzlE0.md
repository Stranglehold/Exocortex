## The Counter Component

```html
<div x-data="{ count: 0 }" style="padding:1rem;display:flex;gap:1rem;align-items:center">
    <button @click="count--" style="padding:.25rem .75rem">−</button>
    <span x-text="count" style="min-width:2rem;text-align:center">0</span>
    <button @click="count++" style="padding:.25rem .75rem">+</button>
</div>
```

### How It Works:
- **`x-data="{ count: 0 }"`** — Initializes Alpine.js reactive data with `count = 0`
- **`@click="count--"`** — Decrement button decreases the counter
- **`x-text="count"`** — Binds the span text to the reactive `count` value
- **`@click="count++"`** — Increment button increases the counter
