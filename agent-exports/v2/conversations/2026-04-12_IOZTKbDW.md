# Debugging Python Extensions in Agent Zero

## Common Causes & Solutions

### 1. **Extension Placement**
Extensions must be placed in the correct directory structure:

```bash
# For custom tools/plugins:
/a0/usr/plugins/<plugin_name>/tools/

# For skills:
/a0/usr/skills/
```

### 2. **Tool Registration Issues**
Agent Zero uses AST parsing to discover tools automatically. Verify your tool class follows the pattern:

```python
from helpers.tool import Tool

class MyExtension(Tool):
    def __init__(self, agent_context):
        super().__init__(agent_context)
    
    async def my_method(self, arg1, arg2):
        # Implementation here
        pass
```

### 3. **Python Environment Mismatch**
Agent Zero uses two Python environments:
- `/opt/venv-a0` (Python 3.12) - Framework runtime
- `/opt/venv` (Python 3.13) - Agent execution runtime

Extensions run in the framework environment (`/opt/venv-a0`).

### 4. **Import Errors**
Check for unresolved dependencies:
```bash
# Test import directly
/opt/venv-a0/bin/python -c "from your_module import YourClass"
```
