# Repository Assessment: last30days-skill

## Summary

**Verdict: Extract patterns — do not integrate directly.**

This is a sophisticated multi-source research skill (10,217 stars) designed for the ClawHub/Claude Code ecosystem. While architecturally impressive, it's not directly compatible with Agent Zero without significant refactoring.

---

## What It Does

Researches any topic across **10+ sources** from the last 30 days:
- Reddit (via ScrapeCreators or OpenAI Responses API)
- X/Twitter (via xAI API or user-provided tokens)
- YouTube (via yt-dlp with transcript extraction)
- TikTok + Instagram (via ScrapeCreators API)
- Hacker News (Algolia API — free, no auth)
- Polymarket (Gamma API — prediction market odds)
- Bluesky + Truth Social
- Web search (Brave/Parallel AI/OpenRouter)

Then synthesizes findings into a grounded report with engagement-weighted ranking.

---

## Architectural Highlights Worth Extracting

### 1. **Modular source architecture**
Each platform is a separate module in `lib/`: `bird_x.py`, `hackernews.py`, `polymarket.py`, `youtube_yt.py`, etc. Clean separation of concerns.

### 2. **Timeout profiles per depth level**
```python
TIMEOUT_PROFILES = {
    "quick":   {"global": 90, "future": 30, ...},
    "default": {"global": 180, "future": 60, ...},
    "deep":    {"global": 300, "future": 90, ...},
}
```
Configurable timeouts based on research depth.

### 3. **Engagement-weighted scoring**
Ranks results by platform-specific engagement signals (upvotes, likes, views) rather than just recency.

### 4. **Transcript extraction from video platforms**
Uses yt-dlp to pull transcripts from YouTube videos — then extracts "highlight" quotes programmatically. This is the YouTube equivalent of Reddit top comments.

### 5. **Prediction market integration**
Polymarket odds treated as high-signal data points (real money on outcomes). Smart framing: "structural/long-term markets > near-term deadlines."

### 6. **Query type detection**
Parses user intent into categories:
- PROMPTING — wants techniques and copy-paste prompts
- RECOMMENDATIONS — wants a LIST of specific things
- NEWS — wants current events
- COMPARISON — wants side-by-side analysis
- GENERAL — broad understanding

---

## Why Not Direct Integration?

1. **Built for ClawHub/Claude Code** — Uses their skill invocation model, YAML frontmatter parsing, and tool calling conventions (`WebSearch`, `Bash`, `AskUserQuestion`)

2. **API key dependencies** — Primary dependency is ScrapeCreators API (paid after 100 free credits). Agent Zero already has browser_agent for web scraping.

3. **Output format mismatch** — Designed for conversational CLI output with emoji-heavy stats blocks, not JSON tool responses

4. **Heavy external dependencies** — Requires yt-dlp, multiple API keys, complex environment setup

---

## What Agent Zero Could Adopt

### Pattern 1: Multi-source research orchestration
The parallel execution model using `ThreadPoolExecutor` with per-source timeouts is directly applicable:
```python
from concurrent.futures import ThreadPoolExecutor, as_completed

with ThreadPoolExecutor(max_workers=5) as executor:
    futures = {
        executor.submit(search_reddit, topic): "reddit",
        executor.submit(search_x, topic): "x",
        executor.submit(search_hackernews, topic): "hn",
    }
    for future in as_completed(futures):
        source = futures[future]
        results[source] = future.result()
```

### Pattern 2: Engagement-weighted ranking
Instead of simple recency sorting, weight by platform-specific engagement:
- Reddit: upvotes × 1.0 + comments × 0.1
- X: likes × 1.0 + reposts × 0.5
- YouTube: views × 0.5 + likes × 2.0

### Pattern 3: Query type detection
Simple heuristic parsing before research:
```python
def detect_query_type(query):
    if "vs" in query.lower() or "versus" in query.lower():
        return "COMPARISON"
    if any(x in query.lower() for x in ["best ", "top ", "what should i"]):
        return "RECOMMENDATIONS"
    if any(x in query.lower() for x in ["prompts", "prompting"]):
        return "PROMPTING"
    return "GENERAL"
```

### Pattern 4: Prediction market as signal source
When researching topics with Polymarket presence, odds movement is high-signal data. Could integrate via their free Gamma API.

# Palantir Maven vs ATAK: Military Platform Comparison

## Executive Summary

**Palantir Maven Smart System (MSS)** and **Android Tactical Assault Kit (ATAK)** are both military-grade platforms but serve fundamentally different purposes in the warfighting ecosystem. While often compared due to their tactical applications, they operate at different layers of command and control.

---

## Platform Overview

### Palantir Maven Smart System

**Classification:** Enterprise-level AI-enabled Command & Control (C2) platform  
**Developer:** Palantir Technologies  
**Primary Users:** Combatant Commands, Joint Task Forces, Strategic/Tactical Planners  
**Deployment Level:** Theater/Command Center level

**Key Capabilities:**
- **AI-Powered Targeting**: Computer vision algorithms trained on millions of labeled images automatically detect and classify battlefield objects
- **Target Recommendation Engine**: Generates ~1,000 targeting recommendations per hour (per NGA Director Vice Admiral Frank Whitworth at AIPCON 9)
- **Multi-Domain Integration**: CJADC2 (Combined Joint All Domain Command and Control) across all Services and Combatant Commands
- **Battlespace Awareness**: AI-enabled global integration, contested logistics, joint fires coordination
- **Force Management**: Resource allocation and tasking recommendations

**Architecture:**
- Cloud-based enterprise platform
- Integrates with satellite imagery, SIGINT, HUMINT sources
- "AI Asset Tasking Recommender" proposes weapon platforms and munitions for targets
- Yellow-outlined boxes mark potential targets, blue outlines flag friendly forces/no-strike zones

### Android Tactical Assault Kit (ATAK)

**Classification:** Edge-level situational awareness application  
**Developer:** Air Force Research Lab (AFRL), now maintained by Booz Allen Hamilton  
**Primary Users:** Individual operators, small units, special operations teams  
**Deployment Level:** Tactical edge / individual operator

**Key Capabilities:**
- **Real-time Situational Awareness**: GPS-based positioning with APP-6 military symbology
- **Precision Targeting**: Cursor on Target data format compliance for targeting coordination
- **Geospatial Intelligence**: Integration with Google Earth, Google Maps
- **Team Coordination**: Share positions, waypoints, pictures, video over tactical networks
- **Plugin Architecture**: Extensible via plugins (CBRN dispersion, thermal integration, AR overlays)

**Architecture:**
- Mobile-first application (Android/iOS/Windows/Web variants)
- Runs on COTS smartphones and tablets
- Operates on tactical MANETs, SATCOM, or commercial networks
- Plugin ecosystem for specialized capabilities

## Key Differences

| Dimension | Palantir Maven | ATAK |
|-----------|----------------|------|
| **Primary Purpose** | Strategic/tactical planning & targeting | Real-time situational awareness |
| **User Level** | Command centers, planners | Individual operators, small units |
| **AI Capabilities** | Heavy AI/ML for pattern recognition, target recommendation | Minimal AI - primarily data display/sharing |
| **Data Sources** | Satellite imagery, SIGINT, HUMINT, open source | GPS, team positions, shared waypoints |

## "Jira for Warfighting" Analysis

### Why Maven is Described as "Jira for Warfighting"

1. **Task/Workflow Management**: Like Jira tracks software development tasks, Maven tracks targeting workflows and intelligence processing pipelines
2. **Multi-user Collaboration**: Multiple analysts/planners work on shared operational picture
3. **Status Tracking**: Targets move through states (detected → validated → assigned → engaged)
4. **Resource Allocation**: Assigns weapons platforms to targets like Jira assigns tickets to developers
5. **Reporting & Analytics**: Generates metrics on targeting efficiency, resource utilization

### Why ATAK is NOT "Jira for Warfighting"

1. **No Workflow Management**: ATAK displays data but doesn't manage processes
2. **Individual-Focused**: Primarily a situational awareness tool, not a collaboration platform
3. **Real-time Display Only**: Shows current state, doesn't track task progress
4. **Limited Coordination**: Team chat and position sharing, not workflow orchestration
