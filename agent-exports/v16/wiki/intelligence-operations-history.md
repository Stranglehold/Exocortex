## SIGINT Timeline

| Era | Development | Operational Impact |
|---|---|---|
| WWI (1914-18) | Room 40, British naval cryptanalysis | First organized signals intelligence operation |
| WWII (1939-45) | Bletchley Park ENIGMA; OP-20-G HF/DF on U-boats | Decisive strategic advantage in Atlantic theater |
| Early Cold War | VENONA project (Soviet cipher interception) | Longest peacetime SIGINT op — data processed until 1958 (34 years post-war) |
| 1970s-90s | ECHELON network, NSA global intercept stations | Shift from tactical to strategic signals collection |
| Modern era | USNS Mission Capable class ships, MEWSS PIP systems | Distributed mobile platforms; EA integration with SIGINT |

## Key Data Points

- **VENONA**: 68,000 conversations fully transcribed. Recording volume: 4,000ft of teletype reel per day.
- **HF/DF** (High Frequency Direction Finding) deployed on US warships starting 1940 — ad-hoc installations evolved into modern shipboard intercept vans.

## ACH Framework

Analysis of Competing Hypotheses (Richards Heuer, CIA):

1. Identify possible hypotheses about the target
2. Generate arguments/evidence for and against each
3. Analyze to determine which hypotheses best explain all available evidence
4. Refine by considering additional evidence or eliminating implausible hypotheses

**Key principle**: ACH forces negation analysis — evidence that argues *against* each hypothesis, reducing confirmation bias.

## Patterns & Connections

- **VENONA compounding value**: Intelligence value compounds over time. Raw WWII intercept data still yielded actionable insights into Soviet nuclear programs and GRU operations in the late 1950s.
- **Signal discrimination**: The core problem — distinguishing noise from actionable intercept — maps directly to working memory decay/promotion mechanics in agent architecture.
- **Source reliability scoring**: HUMINT tradecraft of ranking sources by reliability before ingestion parallels selective memorizer signal discrimination patterns.
