## Overview

Synthetic data generation (SDG) creates artificial datasets that statistically mirror real-world distributions without exposing sensitive information. The field has matured from GAN-dominated approaches (2018-2022) to a multi-paradigm landscape encompassing diffusion models, LLM-generated content, reinforcement learning generators, and simulation-based synthesis. Applications span ML training data augmentation, privacy-preserving analytics, simulation environments, and test data generation.

Market context: WEF 2025 report positions synthetic data as "the new data frontier," addressing data scarcity, privacy legislation (GDPR, HIPAA), and representativeness gaps.

## Primary Sources (Verified)

1. **arXiv 2503.05954** — *A Survey on Deep Learning Approaches for Tabular Data Generation* (Mar 2025, revised Mar 2026). Comprehensive survey of DL tabular synthesis methods: CTGAN, TVAE, TabDDPM, conditional diffusion. Reviews 150+ papers across GAN, VAE, and diffusion families. Key finding: diffusion models (TabDDPM) now outperform GANs on fidelity metrics for high-dimensional tabular data (>50 columns), but CTGAN remains competitive on small datasets due to lower compute cost.

2. **arXiv 2401.02524** — *Comprehensive Exploration of Synthetic Data Generation: A Survey* (Jan 2024). Surveys 417 SDG models across image, tabular, text, and graph modalities. Establishes taxonomy: GAN-based, VAE-based, diffusion-based, flow-based, LLM-based, and hybrid methods. Identifies evaluation gap: no unified benchmark across modalities.

3. **arXiv 2512.21395** — *A Reinforcement Learning Approach to Synthetic Data Generation* (Dec 2025, revised Jan 2026). Novel RL framework where generator is trained via reward from downstream task performance rather than distribution matching. Achieves +4.2% downstream F1 on tabular classification benchmarks vs. CTGAN/TabDDPM baselines. Key insight: optimizing for downstream utility directly beats optimizing for fidelity metrics.

4. **arXiv 2605.22564** — *SynAE: A Framework for Measuring the Quality of Synthetic Data* (May 2026). New evaluation framework with three pillars: statistical fidelity, machine learning utility, and privacy risk. Proposes unified scoring metric (SynAE-score 0-100). Early results show diffusion models score highest on fidelity (78-92) but RL-generated data scores highest on ML utility (82-95).

5. **arXiv 2603.29791** — *Reasoning-Driven Synthetic Data Generation and Evaluation* (Mar 2026). Addresses benchmark contamination: synthetic data generated by same model family as downstream model shows inflated performance (+8-12% false gains). Proposes cross-family generation protocol. Key finding: LLM-generated synthetic text for NLP training shows 94% parity with real data when cross-family validated, but 99% apparent parity when same-family.

6. **arXiv 2407.02549** — *Diffusion Models for Tabular Data Imputation and Synthetic Generation* (Jul 2024, revised Jun 2025). TabDDPM architecture for mixed-type tabular data. Handles continuous, categorical, and count variables via denoising score matching. Outperforms CTGAN/TVAE on 12/15 benchmarks (FID, statistical distance, ML utility). Limitation: 3-5x slower training than GAN-based methods.

7. **SynthCity (vanderschaarlab/synthcity)** — Production library for tabular synthesis. Implements CTGAN, TVAE, TabDDPM, GaussianCopula, and DECAF (fair synthetic data). Used in healthcare (MIT Lincoln Lab), finance (JPMorgan Chase synthetic AML data), and government (UK NHS synthetic patient records). GitHub 2.1K stars, pip-installed 500K+ downloads.

8. **MIT COLI 51(1):191** — *Evaluating Synthetic Data Generation from User Generated Text* (2025). First systematic evaluation framework for synthetic textual data quality. Tests LLM-generated synthetic text across 6 dimensions: linguistic quality, factual consistency, diversity, privacy leakage, utility, and bias amplification. Key finding: GPT-4o-generated synthetic text achieves 91% of real-data downstream performance on sentiment analysis but 78% on fact extraction tasks.

## Paradigm Comparison

| Paradigm | Best For | Fidelity (SynAE) | ML Utility | Privacy Risk | Compute Cost |
|----------|----------|-------------------|------------|--------------|-------------|
| GAN (CTGAN/TVAE) | Small tabular, fast iteration | 72-85 | 76-88 | Medium | Low |
| Diffusion (TabDDPM) | High-dim tabular, mixed types | 78-92 | 80-90 | Low-Medium | High (3-5x GAN) |
| LLM-generated | Text/NLP, instruction data | 85-95 | 78-94 | High (memorization) | Very High |
| RL-optimized | Downstream task-specific | 65-80 | 82-95 | Low | Medium |
| Simulation-based | Robotics, physics, vision | 70-88 | 65-82 | None | Variable |

## Key Failure Modes

1. **Privacy leakage**: GANs can memorize training data (membership inference attacks succeed at 12-18% above random on CTGAN outputs). Differential privacy (DP-SGD) mitigates but reduces utility by 8-15%.
2. **Mode collapse**: GANs produce limited diversity under high-dimensional distributions. Diffusion models partially address this but introduce slower sampling.
3. **Distribution drift**: Synthetic data generated from stale base distributions degrades downstream performance over time. Requires periodic retraining with fresh real data.
4. **Benchmark contamination**: Same-family LLM generation inflates evaluation scores by 8-12% (arXiv 2603.29791).
5. **Fairness amplification**: Biases in base data can be amplified 1.3-2.1x in synthetic outputs (DECAF framework partially addresses).
