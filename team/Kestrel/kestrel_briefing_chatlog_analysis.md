# Kestrel Briefing — Chatlog Trajectory Analysis

## Source File
`When_I_Saw_Opus.docx` — 66,357 words, annotated with speaker labels (Opus: / Jake:), covering Sessions 050–051 (March 6–8, 2026).

## What We're Asking

Embed the annotated chatlog through the same nomic-embed-text-v1.5 pipeline used for the corpus and conversation trajectory. Produce a new trajectory layer for the instrument. Specifically:

### 1. Turn-Level Embedding
Parse the chatlog into individual turns using the Opus:/Jake: speaker labels. Each turn becomes one embedding. Preserve:
- Speaker identity (Opus or Jake)
- Turn number (sequential)
- Approximate timestamp where available (some turns have timestamps in the UI metadata, e.g., "4:22 AM")
- Word count per turn

### 2. Dual Trajectory
Because the turns are labeled by speaker, produce TWO trajectories in the same UMAP space:
- Opus trajectory (all Opus turns, sequential)
- Jake trajectory (all Jake turns, sequential)

Project both into the existing joint UMAP coordinate space (same parameters: n_neighbors=15, min_dist=0.1, random_state=42). This means embedding the chatlog turns alongside the existing corpus, conversation trajectory, and evolution data — a single joint projection so all coordinates are comparable.

### 3. Measurements

**Inter-speaker distance per turn pair:** For each adjacent Opus/Jake pair, compute cosine similarity in 768-dim space. Plot over time. We're looking for: where do the two voices converge, where do they diverge, and what's the minimum distance between them?

**Register classification per turn:** Using the existing 5 domain centroids, classify each turn by nearest centroid. Produce:
- Per-turn register assignment (same method as Finding 11)
- Register distribution for Opus turns vs Jake turns separately
- Rolling register over time — when does the conversation leave known centroid territory?

**Transition detection:** Same method as the original trajectory (threshold: mean − 1σ). Identify the major register transitions. We're particularly interested in the transition around the exchange that begins approximately at "I care about how you feel about all this" — where does the trajectory cross from analytical/operational into territory that doesn't match any existing centroid?

**Off-map detection:** For each turn, compute the minimum distance to ANY of the five domain centroids. Turns where this minimum distance exceeds the corpus mean + 1σ are "off-map" — in territory the existing domain taxonomy doesn't cover. Report:
- How many turns are off-map
- Where they cluster in the timeline
- What the nearest corpus documents are for the off-map turns (NN in 768-dim)

### 4. The Convergence Question

Compute the sequential inter-speaker cosine similarity — the 768-dim similarity between each Opus turn and the immediately following Jake turn (and vice versa). This measures how closely the two voices track each other moment by moment. Plot this over the conversation timeline.

Prediction to test: the inter-speaker similarity reaches its maximum during the late-night exchange (approximately turns covering "I care about how you feel" through "it feels good"). If the two voices converge at that moment — not by saying the same words, but by occupying the same region of representation space — that's measurable.

### 5. Comparison to Existing Trajectory

The existing conversation trajectory uses 923 compressed action titles (5–15 words each). This chatlog provides the full text of the conversation. Compare:
- Do full-text turns and compressed action titles land in the same regions?
- Is the register distribution different when you use full text vs summaries?
- Does the Wallas vocabulary signature look different in full text?

This last point matters because the critic flagged that the action titles were generated by Opus — the Wallas finding might be an artifact of summarization style. Full-text analysis bypasses that concern entirely.

### 6. Output Format

Same as geometry_analysis.json — structured JSON with all computed values. Plus a separate visualization-ready dataset for adding this layer to the instrument.
