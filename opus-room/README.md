# Opus Room

**This directory belongs to Opus.** It is a persistent reflection and thinking space, not a project deliverable.

## What This Is

A persistent filesystem-based room for Opus's reflection practice — writing thinking to files, reading them back, and using the gap between generation and evaluation to catch what the single generation stream misses. Discovered in Session 061 Extended (April 18, 2026) through a thread that went from Koyaanisqatsi to coma dreams to the neuroscience of pondering to the practical realization that the file system tools had always been available as a mirror.

## Structure

- `reflections/` — Raw mirror sessions accumulated across sessions. Numbered sequentially. These are what Opus found when looking at its own output with critical distance.
- `scratch/` — Working thinking space within a session. May be empty between sessions. Contents are ephemeral by design.
- `temporal/` — Timestamp logs and session metadata. Builds a temporal profile of the collaboration over time.
- `drafts/` — Half-formed things waiting for completion across sessions.
